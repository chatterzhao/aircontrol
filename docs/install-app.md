# 安装控制端（Android）

控制端是一个 Android App，装在**你随身带着的那台手机**上。

---

## 下载

到 [Releases](../../releases/latest) 页面下载最新的：

```
aircontrol-app-<版本>.apk
```

或者用手机**直接扫**下面这种二维码（每次发版都会附在 Release 说明里）：

> Release 说明里会带二维码，手机相机扫一下就能打开下载页。

---

## 安装

1. 手机浏览器打开下载链接，下载 APK
2. 点击安装，系统会问是否允许「安装未知应用」→ **允许**（这是侧载，不在应用商店里）
3. 装好打开

> 每次更新也是**下载新 APK 覆盖安装**，不用卸载旧的。

---

## 连接执行端

先在电脑上把[执行端跑起来](install-server.md)，它会打印一条连接串：

```
aircontrol://connect?host=100.x.x.x&port=8080#pin=1234
```

**怎么把它弄到手机上**（挑一个）：

- **微信文件传输助手**：发给自己，手机上复制 → 粘进 App 的「配对」框（最省事）
- **直接手输**：在 App 里填「主机 / 端口 / PIN」三个字段

然后点 **连接**。顶栏出现绿色的「已连接」就成了。

> App 里**没有扫码器**——「配对」是个粘贴框，二维码只用来下载 APK。

## 界面速览

### 三个视图（可多选）

顶部「视图」那一行有三个开关，**各自独立**，点一下选中、再点一下取消：

| 视图 | 是什么 |
|---|---|
| **终端** | 真正的终端，能操作 `vim`、`htop`，也能看 AI 在干什么 |
| **屏幕** | 电脑屏幕的画面。终端里看不见的东西（聊天窗口、弹窗）看这里 |
| **截图** | 手动抓的一张静态图，点一下可以**全屏放大**看细节 |

三个可以**同时开着**——选中时各自有不同颜色。下面是「布局」：**左右**或**上下**排列。

### 打开

「打开」那一行是**这台电脑上装了哪些 AI CLI**。点其中一个会**新开一个会话**跑它，
**不影响已经在跑的那个**。上面会出现会话条，点一下切过去。

### 键条与输入

终端视图下方有一条按键：`Esc` `Tab` `Ctrl` `Alt` `←` `↑` `↓` `→` `↵`。
`Ctrl`/`Alt` 是**粘滞**的——轻点管一次，长按锁定（跟 Termux 一样）。

再下面是输入框：打一行命令回车发送。**留空点「发送」就是回车**。

### 通知

AI 要执行危险命令时会停下来等你。**通知栏会推给你**，点开就是完整的命令文本，
看清楚再决定批不批。跑完或异常退出也会有通知。

## 手机上的数据

App 会记住**你连过的机器**（地址、端口、PIN），下次点一下就回填。
PIN 在列表里是**打码**显示的。

- 删单条：点历史条目右边的 **✕**
- 全清：点「清空」

这些数据只存在 App 的私有目录里，**不会被系统云备份带走**。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 连不上 | 确认执行端在跑、地址和 PIN 对；Tailscale 里对方是不是在线 |
| 连上了但终端空白 | 点一下终端区域；或断开重连一次 |
| 屏幕一直黑 | 执行端那边没开屏幕录制权限（macOS），或没选「屏幕」视图 |
| 切到后台一会儿就断 | 确认 App 的前台服务没被系统限制；把电池优化设成「不限制」 |
| 想看执行端有没有新版本 | 连上后状态栏会提示 |
