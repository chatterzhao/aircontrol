# 在 Linux 服务器上部署执行端

执行端是 **Kotlin/JVM** 程序，所以 **macOS / Linux / Windows 都能跑同一份产物** ——
不是三套代码，是同一个 JVM 程序。本文说 Linux（尤其是**没有图形界面的服务器**）。

> ⚠️ 本文**不记录任何真实地址、密钥或凭据**。
> 文中出现的 IP 一律是 `192.168.1.100`、`100.x.x.x` 这类**示例值**。

---

## 一、它需要什么

| 需要 | 说明 |
|---|---|
| **Java 17+** | 没有也行 —— 安装脚本会带一个**便携 JRE**，见下 |
| **`tmux`（可选）** | 没有也能连、能用单会话；**只是会话管理用不了**（新建/切换/重开报 `E004`） |
| `unzip` / `curl` | 安装脚本用 |
| 一个放设备的目录 | 默认 `~/.aircontrol`，**不需要 root** |

**不需要**：root、系统包、数据库、图形界面。

---

## 二、安装

```sh
# 1) 把安装脚本拷到服务器（或直接在服务器上下载它的 URL）
#    脚本本身是纯文本，不需要编译。

# 2) 跑它
sh install.sh --version 0.1.37
```

装到 `~/.aircontrol`：`bin/daemon` + `lib/*.jar`。

### 没有 Java 怎么办

脚本会**自己带一个便携 JRE**，解压到 `~/.aircontrol/jre`，
**完全不碰系统**（不装包、不要 root、不改 PATH）。

**如果服务器不能访问外网**（生产环境常见），这一步会失败。那就**在能上网的机器上下好再传**：

```sh
# 在能上网的机器上（Linux x64 的官方 Temurin JRE）
curl -fL -o jre.tgz \
  'https://api.adoptium.net/v3/binary/latest/17/ga/linux/x64/jre/hotspot/normal/eclipse'

# 传到服务器
scp jre.tgz 你的服务器:/tmp/

# 在服务器上解开
ssh 你的服务器 'mkdir -p ~/.aircontrol/jre && \
  tar xzf /tmp/jre.tgz -C ~/.aircontrol/jre --strip-components=1 && \
  ~/.aircontrol/jre/bin/java -version'
```

架构不是 x64 就把 URL 里的 `x64` 换成 `aarch64`。

## 三、启动

```sh
export JAVA_HOME=$HOME/.aircontrol/jre        # 用了便携 JRE 才需要
$HOME/.aircontrol/bin/daemon --ws-port 8080
```

### ⚠️ 别用 `nohup ... &` 直接起 —— 除非你读下面这段

配对时要**在终端上按 `y` 同意**。而 `nohup ... &` 会把 **stdin 断开**，
于是**敲不了字** ✗。

三种可行的起法：

| 起法 | 配对时怎么同意 |
|---|---|
| **SSH 里前台跑** | 提示直接出现，敲 `y` ✓ |
| **`tmux` / `screen` 里跑** | 随时 attach 回去，敲 `y` ✓ |
| **`nohup ... &`（stdin 断了）** | 用**批准文件**，见下 ✓ |

#### 无界面服务器：用批准文件

```sh
echo y > ~/.aircontrol/approve    # 同意这次配对
echo n > ~/.aircontrol/approve    # 拒绝
```

任何 SSH 会话都能做。文件**用完立刻被删掉** ——
留着的话下一个设备会被自动批准，那等于把审批变成常开。

> **这不降低安全性**：能写这个文件的人，本来就已经有这台机器的 shell 了。
> 对"拿到了连接码、但没有 shell"的攻击者，它一点帮助都没有。

### 推荐的起法（会保住会话）

```sh
tmux new -d -s aircontrol \
  "$HOME/.aircontrol/bin/daemon --ws-port 8080"
tmux attach -t aircontrol          # 随时进去看码、按 y、按 d
```

## 四、配对

1. **手机连上这台机器**（填 `地址:8080` + 连接码，或扫码）
2. **服务器终端**会打出：

   ```
   [daemon] ──────────────────────────────────────────────
   [daemon] 设备「xxx」想连接（来自 <来源>）。
   [daemon] 如果就是你现在正在连的这台，按 y 回车允许；
   [daemon] 不认识它就按 n 回车拒绝（也可以不理，60 秒后自动拒绝）。
   [daemon] ──────────────────────────────────────────────
   ```

3. **按 `y`**（或 `echo y > ~/.aircontrol/approve`）
4. 手机拿到**设备令牌**，之后重连**不再需要任何码** ✓

**没点同意，什么都进不来** —— 即使连接码被猜到也一样。

---

## 五、终端上的按键

| 按键 | 作用 |
|---|---|
| **回车** / `r` | 换一个**临时连接码**（3 分钟那个） |
| `d` | 删掉**永久连接码**并换一个新的（旧的立刻作废） |
| `y` / `n` | 有设备在等批准时，同意 / 拒绝 |
| `h` / `?` | 显示帮助 |

---

## 六、两种连接码

| | 临时码 | 永久码 |
|---|---|---|
| 长度 | 4 位数字 | **6 位混合字符**（大小写+数字+符号） |
| 有效期 | 3 分钟 | 除非你按 `d` 删掉 |
| 用几次 | **一次**（用过即废） | 反复用 |
| 空间 | 10^4 | 62^6 ≈ **570 亿** |
| 适合 | 给客人、临时设备 | **你自己的手机** |

**永久码区分大小写** —— 手机输入法可能自作主张把首字母大写，注意。

**永久码只在生成时打印一次**（之后只存 SHA-256，读不回来）。错过了就按 `d` 换一个。

---

## 七、卸载

```sh
rm -rf ~/.aircontrol
```

**就这一条** —— 没往系统里放过任何东西。

---

## 八、当前**不可用**的部分（诚实标注）

以下在**没有 tmux** 的服务器上**不可用**，会明确报 `E004`：

- 新建会话、切换会话、重开会话、忘记会话
- 「打开一个大脑」（在 tmux 新窗口里起 AI CLI）

**能用的**：单会话终端、发命令、看输出、屏幕画面、心跳、审批。

想用会话管理就装 tmux：

```sh
sudo apt install tmux          # Debian/Ubuntu
sudo dnf install tmux          # RHEL/CentOS/OpenCloudOS
```

**已实测**（Linux 6.6 x86_64，无 Java、无 tmux）：

- ✅ 便携 JRE 解压后能跑
- ✅ 执行端启动、打印两种连接码
- ⏳ **待复核**：手机连上该服务器、批准文件生效、终端回显
  （这几步需要在同一网络里同时操作手机和服务器）
